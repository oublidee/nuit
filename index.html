Connecter mon Mac

Service local requis

Le site affiche l’interface. Le service local réalise les téléchargements sur ton Mac et garde ta session Brave sur ton ordinateur.

  1. Télécharge service.php dans un dossier dédié. Dans Terminal, ouvre ce dossier et lance :
    php -S 127.0.0.1:8787 service.php
    Aide à l’installation des outils ↗
  2. Ouvre le service local ↗, choisis ton dossier, puis clique sur « Autoriser le site pendant 8 heures ».
  3. Colle ici le code privé donné par le service local. Brave pourra demander l’autorisation d’accéder à cet ordinateur.

La connexion au Mac démarre uniquement quand tu cliques sur « Connecter ».

Vérification automatique et silencieuse à chaque ouverture. PHP est nécessaire au démarrage de la page ; s’il manque, installe-le avec brew install php dans Terminal.
À exécuter dans Terminal avec Homebrew, puis clique sur « Vérifier à nouveau ». Aucune installation ne se lance sans ton intervention.
